🔩 Screw Master

游戏规则与逻辑梳理 · 拧螺丝解谜（木板 + 钢板 + 螺丝）

目标 你在玩什么

一块铺满整个画面、带有成排钻孔的木质背板，上面钉着若干块钢制铁片。 每块铁片由 2 颗螺丝固定。你的任务：

① 拧下所有螺丝
→
② 让每块铁片失去支撑
→
③ 铁片自由落体坠出屏幕
→
④ 清空全部铁片 = 过关

只有 2 个空余主板孔 可以临时存放拔下的螺丝——这是整个谜题的"资源预算"，也是难度核心。

元素 场景构成

🪵 木质背板满屏木纹 + 暗角，板上分布着网格状的钻孔（深色孔 + 内壁阴影）。螺钉最终都落在这些孔里。
🕳️ 主板钻孔背板上的固定孔位。每个孔要么有螺丝、要么空着。开局恰好 2 个空孔。
🔩 螺丝钉把铁片固定在背板上的金属螺栓（径向高光圆头 + 六角凹槽）。被铁片盖住时半透明 + 红叉表示"够不着"。
🟦 钢板 / 铁片多边形金属板，6 种形状：bar / L / T / tri / ell / square。每块有 2 个销孔（pin），由 2 颗螺丝穿过固定。

钢板上的两个销孔始终可见——即使螺丝被拔出，孔洞（沉头环 + 暗色内孔）也会保留在铁片上，不会消失。

操作 怎么玩

  • 拔出螺丝：点击一颗可访问的螺丝 → 它"拿在手上"，跟随鼠标/手指移动。
  • 安装螺丝：再点击一个干净的空主板孔 → 螺丝钉入该孔。
  • 取消 / 换孔：拿着螺丝时，点别处合法空孔即可改放位置。
  • 每一步（拔 + 装）都会记入撤销栈，可 Undo 回退。

两级操作（先点螺丝、再点空孔）是故意设计的——它让"拔哪儿、放哪儿"成为谜题本身。

规则 核心逻辑

R1螺丝可访问性（accessible）：一颗螺丝能拔，当且仅当它没有被"仍被螺住"的铁片盖住。 具体：如果某块铁片盖住了这颗螺丝，且这块铁片至少有一颗螺丝没拔（仍是"拧紧"的），则螺丝够不着 → 不可拔。 如果盖住它的铁片两颗螺丝都已拔掉（只是松脱搁在那儿），那颗螺丝仍可拔 → 可拔。
R2空孔可用性（isFree / plateHitsHole）：拔下的螺丝只能装进100% 完全裸露的主板孔。 孔的判定范围 = 暗孔 + 外圈金属倒角（半径 18px 的圆）。只要任何铁片与这个圆有任意相交——完全盖住、盖住一半、盖住 1/3，或任意边缘擦到倒角圈 → 都 不可装。 没有 own-pin 例外：铁片自己的销孔也一样，只有当铁片歪开/掉走、销孔完全露出来时才能插回；被自己（或任何铁片）挡住一点点都不行。 判定用铁片的实时轮廓（悬挂倾斜的旋转、自由落体的位移/旋转都算）——屏幕上看到什么挡着，什么就算挡。
R3铁片掉落（releasePlates）：当一块铁片同时满足以下三条，它才会坠离：
  1. 它的 2 个销孔都空了（螺丝都拔出）；
  2. 它正下方没有仍插着的螺丝顶着它（cov[i] 内无螺丝）；
  3. 它正下方没有未坠落的铁片撑着它（ov[i] 内无未 gone 板）。
每帧检测，所以下层铁片一掉，上面压着的铁片会级联跟着掉。
R4层级遮挡（下面挡上面）：生成关卡时按真实几何重叠分配 layer——若两板重叠且中心 y 差 ≥ 8px，靠上的板 layer 更高。 ov[i] = 比 i 层低且与 i 重叠的板；cov[i] = 落在 i 多边形内的所有主板孔。这是"上面能挡住下面 / 下面能撑住上面"的数学依据。
R5销孔永久可见：铁片上的 2 个销孔在渲染时始终绘制，与螺丝是否存在无关。螺丝只是"坐在"沉头孔里；螺丝一拔，空孔保留。
R6插回螺丝 ≠ 自动回正：铁片只拔了 1 颗、挂在剩下那颗上（倾斜）时，若把那颗螺丝重新插回原孔，铁片会保持当前倾斜姿态、被两颗螺丝冻结住，不会自动回正成水平。即：一旦铁片下垂过，它就"歪着"留在板上，直到你把两颗螺丝都拔掉让它整块坠落。这是为了游戏手感（下垂造成的歪斜不可逆），属刻意设计。

物理 单摆下垂 & 自由落体

① 单颗螺丝拔出 → 钟摆下垂（droop）

当铁片只剩 1 颗螺丝时，它不再平贴，而是以剩余那颗螺丝的孔为支点做单摆，自由端慢慢垂下，带阻尼与轻微回弹。 下垂角度被下方障碍钳制：

  • 若下方有插着的螺丝或未坠落的铁片，自由端销孔不会跌破障碍 y − 30px，铁片就搁在障碍上被挡住，绝不会穿过去。
  • 障碍一旦被清掉（螺丝拔走 / 下层铁片坠落），铁片会继续下摆。

② 两颗螺丝都拔出 → 自由落体（fall）

两颗螺丝都空后，铁片以单摆结束时的姿态为起点（位移补偿 ox/oy 保证不跳变），做纯直坠：无旋转、无碎片喷射、无震屏，掉出屏幕下沿即判定消失。

"位移补偿"是关键：单摆绕支点旋转，落体绕铁片中心旋转，二者支点不同会导致瞬间平移（看起来像弹起）。用 ox/oy = [pv + R(rot)·(c−pv)] − c 把单摆终态"折算"成落体起态，保证下落起点与单摆终点完全一致。

  • 每关恰好 2 个空孔，形成"先拆完一块、再拆下一块"的强制顺序谜题。
  • 安全门：每块铁片只覆盖自己的 2 个销孔（noStray），既消灭死锁又根治"幻影孔"。
  • 可解性：生成器求解器只在干净孔放螺丝，与游戏 isFree 一致 → 8/8 关保证可通关。

辅助 其它功能

↩ Undo每步快照回滚（最多 80 步），误操作时回到上一步。
💡 Hint浏览器内跑同一套 playout 求解器，从当前局面算出"下一步拔哪颗 + 放哪"，高亮提示。
⟳ Restart重新加载当前关卡。
🔊 静音程序化 Web Audio 音效（拧螺丝、钢板哐当、过关号角）+ 轻量 BGM。

Hint 用的是与生成器同源的随机化贪心 playout（优先选能直接让铁片掉落的走法，跑 200~250 次随机重试取一条真解路径）。

技术 实现要点

  • 框架：Next.js 14（App Router）静态导出，STATIC_EXPORT=1 npm run build → out/。
  • 游戏本体：public/games/screw-master/index.html —— 单文件 Canvas，逻辑 960×540，FIT 等比缩放。
  • 状态：holes / plates / screwAt / ov / cov 五个数组；每帧 releasePlates() 检测级联掉落。
  • 几何：pip（点在多边形内）、bboxOf、segInt、polysOverlap 支撑层级遮挡判定。
  • 数据：levels.js 输出 window.SCREW_LEVELS，每关含 holes / plates{type,poly,pins,layer} / screws。
