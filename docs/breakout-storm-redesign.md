# Breakout Storm 重设计方案

## 一、问题诊断
- 当前版本为竖屏（aspect-ratio 3/4），砖块区只有 5 行 × 8 列，横向空间浪费。
- 挡板仅占屏宽 22%，容错率低。
- 一次漏球直接 Game Over，挫败感强。
- 缺少音效与消除反馈，爽感不足。

## 二、设计目标
打造一款横屏、高密度、强反馈的街机风 Breakout/Arkanoid 游戏，强调：
1. 横向铺满、砖块密集。
2. 长挡板，提升掌控感。
3. 3 次生命，右上角可视化。
4. 连续打击有阶梯音效 + 粒子爆炸 + 震屏 + 连击文字。

## 三、具体方案

### 3.1 布局与画布
- 比例：16:9 横屏，沿用 `GameFrame` 的 `aspect-[16/9]`。
- 画布尺寸：内部逻辑 960×540，按容器缩放。
- 砖块：10 列 × 6 行起步，每升 1 关 +1 行（最高 9 行）；每关砖块数 60→90。
- 边距：顶部 48px 给 HUD，左右 8px，砖块间距 4px，让砖块更密。

### 3.2 挡板
- 宽度：屏宽 35%（约 336px@960）。
- 高度：14px，圆角 7px。
- 物理：击球点距挡板中心越远，水平速度越大；最大偏转角 ±60°。
- 视觉：霓虹白 + 底部发光，移动时轻微拖尾。

### 3.3 生命机制
- 初始 3 命，漏球减 1。
- 0 命时游戏结束。
- 右上角用 3 颗小球/心形图标实时展示，损失时图标碎裂动画。

### 3.4 音效（Web Audio API）
- 击球：中频短促“叮”。
- 击墙：高频短促“嗒”。
- 击砖：随 combo 阶梯上升：
  - 1 连：C5
  - 2 连：E5
  - 3 连：G5
  - 4 连：C6
  - 5 连：E6
  - 6+ 连：G6 + 混响 + 低音轰鸣
- 漏球：降调“嗡”。
- 通关：上升琶音。

### 3.5 视觉反馈
- 粒子爆炸：砖块碎裂时向外迸发 8~20 颗彩色粒子，速度/数量随 combo 增加。
- 震屏：每击碎砖块触发 2~6px 随机偏移，combo 越高震幅越大。
- 连击文字：屏幕中央弹出 “×2 / ×3 / ×4 / UNBELIEVABLE / GODLIKE”。
- 球拖尾：运动轨迹留下渐隐光点。
- 砖块光晕：被击中的砖块高亮并缩小后消失。
- 背景：深色星空/网格，砖块霓虹描边。

### 3.6 关卡与难度
- 每关速度提升约 6%。
- 砖块行数增加，颜色按行变化。
- 计分：基础 10 分/砖，连击倍率 ×(1+combo×0.2)。
- 清屏后下一关，保留当前生命。

### 3.7 交互
- PC：鼠标/键盘左右箭头。
- 移动：手指拖拽（相对移动更跟手）。

## 四、文件改动
- `public/games/breakout/index.html`：完整重写。
- `data/games.json`：`title` 改为 “Breakout Storm”，`description` 更新。

## 五、验证标准
- [ ] 横屏 16:9，砖块 10×6 起步且铺满顶部。
- [ ] 挡板明显比球宽且长。
- [ ] 右上角显示 3 命并随漏球递减。
- [ ] 连续击砖有阶梯音效与粒子/震屏/连击字。
- [ ] node --check 与 npm run build 通过，8091 预览可玩。
